# grandmaword

[![make.fun](https://make.fun/badge/u-0xkianno-one-word-from-grandma-f04bed16.svg)](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16)

A one-word entry for the "One Word From Grandma" bounty: **Chatty**. It's the word a grandma would reach for when describing the AI — a warm, slightly baffled, chatty little thing — one word that ties the answer to chat itself while staying fresh and instantly readable.

## Run it

```bash
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

This writes the entry to `./out/entry.txt`.
